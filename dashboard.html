Family Frame

כניסה

הדאשבורד עובד מול הריפו הפרטי שלך ב-GitHub בעזרת טוקן אישי. הטוקן נשמר רק בדפדפן הזה ונשלח רק ל-GitHub.

  1. פתח את יצירת טוקן חדש (Fine-grained).
  2. תחת Repository access בחר Only select repositories ← family-frame.
  3. תחת Permissions תן Read and write ל-Actions, Contents ו-Workflows.
  4. צור את הטוקן והדבק אותו כאן.
